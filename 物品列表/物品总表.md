## 0. 怎么读这份表

### 0.1 三条阅读规则

1. **先看章节（CSV 里的 `分组` 列），再看「合成栏」**。章节回答"这是什么东西"，合成栏回答"玩家在哪一栏找它"——两者不是同一个维度（见 `4.5.12`）。
2. **「图标」列只认文件是否存在**。`✓` 表示 `美术素材/` 下有同名 PNG；`—` 表示缺图，不代表不重要。
3. **「状态」不是质量评级**，是这份表的置信度：`定稿` = 主文档写死；`待确认` = 数值或配方只在归档稿里；`缺口` = 主文档自己都没写全。

### 0.2 口径优先级

```
NoiseDemo.md（v1.12，现行宪法）
   ↓ 覆盖
物品设计.md v0.3 / 烹饪系统.md v0.3 / 战斗系统.md v0.10（已归档，仅作底稿）
```

**归档稿里过时的部分**主要集中在护甲（固定点数 → 百分比）与武器（`v1.9` 重标定）两处，**这两块不要照抄归档稿**。

### 0.3 状态定义

| 状态 | 含义 | 程序处置 |
|---|---|---|
| **定稿** | 主文档有明确数值与获取方式 | 可直接实现 |
| **待确认** | 数值/配方只在归档稿中出现，主文档未复述 | 先实现，但打 `TODO` 标记 |
| **缺口** | 主文档缺少用途、来源或定义 | 实现前必须补齐 |
| **已废止** | 曾被设计后删除 | 不要实现；见第 20 节 |

**核心公式**（`4.5.2`，注意与归档稿的固定点数方案完全不同）：

```
受到伤害 D：
  护甲吸收   = D × 吸收率
  玩家掉体力 = D × (1 − 吸收率)
  护甲耐久  −= 护甲吸收量        ← 扣的是"吸收掉的那部分"
  耐久 ≤ 0  → 碎裂，身体槽清空
```

**修复**：`胶带 +20` 耐久；`金属板 +40`（只能修铁皮护甲 / 安全帽）。
**状态异常不受护甲减免**——护甲管挨打，药管状态。**空手是允许的**（空手伤害 `10`），玩家永远有最低输出。
