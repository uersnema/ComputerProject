# 序列协议 · 规则

> 单人爬塔卡牌游戏。基础架构沿用《杀戮尖塔》，本文只写与它不同的部分。

---

## 0. 与《杀戮尖塔》的差异

| 维度 | 杀戮尖塔 | 序列协议 |
|---|---|---|
| 抽牌堆 / 弃牌堆 / 消耗堆 | 抽空后洗弃牌堆 | 完全沿用 |
| 能量 | 每回合固定恢复 | 沿用，序列可跨回合预支费用 |
| 卡牌去向 | 手牌 → 弃牌堆 / 消耗堆 | 新增「合成区」 |
| 卡牌效果 | 各自独立结算 | 可被别的卡吃掉，成为它的一部分 |
| 伤害计算 | 加法为主 | 乘法为主（循环嵌套 → 倍率） |
| 核心决策 | 打什么、打谁 | 押什么、闭不闭合、何时编译 |

**一句话**：每张卡是一段小程序，用一张卡的开括号往下吃掉后面几张卡的代码。

---

## 1. 卡牌三段式

每张卡从上到下分三段：

```
┌──────────────────────────┐
│ 【头】条件开头 或 循环开头    │  ← 可以没有
├──────────────────────────┤
│ 【体】实际要做的事           │  ← 一定有
├──────────────────────────┤
│ 容量 E：3                 │  ← 只有带【头】的卡有
└──────────────────────────┘
```

| 概念 | 含义 |
|---|---|
| **头** | 开一个块。两种：**条件头**（若……则……）、**循环头**（重复 n 次……） |
| **容量 E** | 这个头能吃掉多少「内容费用」的上限 |
| **块** | 一个头 + 被它吃掉的内容 |

带头的卡单独打出通常没有效果。例外：有些循环头自带效果。

---

## 2. 容量 E 与吃掉

押入一张卡时，它会**从最内层往外**找一个装得下它的块，被那个块吃掉。

1. **看费用，不看张数**：一张卡被吃掉，要消耗掉它打印费用那么多的容量。
2. **全有或全无**：整张卡的费用必须完整放进某个块的剩余容量；放不下就完全留在块外。
3. **容量没用完也能编译**：E 是上限，不是必须填满的配额。

```
① 押入 若敌人生命值 ≤ 50% {      E = 3
② 押入 造成 12 点伤害（1 费）      ← 消耗 1，剩 2
③ 押入 血管爆裂（2 费）           ← 消耗 2，剩 0
④ 押入 重击（1 费）               ← 剩 0，装不下 → 整张留在块外
```

**0 费卡按 0 计算**，不消耗容量。

---

## 3. 闭合

闭合不需要卡牌，随时可用、免费。

作用：关掉**最内层**那个还没关的块。关上之后，后面押入的内容不再被它吃掉。

```
押入  重复 3 次 {            ← 打开循环
押入  造成 5 点伤害           ← 会被重复 3 次
闭合  ｝                     ← 收口
押入  获得 1 层愤怒           ← 只结算 1 次
```

- 只能关最内层（后开先闭，不能跳过内层去关外层）。
- 不关就一直吃：忘记闭合，后面的牌会被意外吞进循环。

---

## 4. 嵌套与费用

块里可以套块，层数不设上限。

### 序列费用

```
序列费用 = Σ(所有押入牌的打印费用)
         + Σ(循环头的结构费)
         − 编译后每回合减 1
下限 0

循环头结构费 = 循环次数 − 1
（例：重复 3 次 → 结构费 2；重复 2 次 → 结构费 1）
```

例：

| 结构 | 费用 |
|---|---|
| 单卡（1 费） | 1 |
| ＋循环 ×2 | 1 + 1 = 2 |
| ＋循环 ×3 | 1 + 2 = 3 |
| ＋循环 ×2 再套 ×2 | 1 + 1 + 1 = 3 |

---

## 5. 条件与循环结算

### 条件：块进入时判定一次

```
重复 3 次 {
    若敌人生命值 ≤ 50% { 造成 5 点伤害 }
}
```

- 条件成立 → 三轮全部执行（15 点）；
- 不成立 → 整块跳过（0 点）；
- 中途不重新判定。嵌套时逐层判定。

### 顺序

从上到下、从左到右、从外到内。内层先算完再回外层。

---

## 6. 合成区

| 规则 | 说明 |
|---|---|
| 容量 | 按张数计（素材位），可随游戏进程提升 |
| 押入 | 不花费用，只能追加到末尾，不能插到中间 |
| 取回 | 押入后不能取回 |
| 弹出 | 免费移出最后一张，进弃牌堆，每回合限一次 |
| 并行 | 同时只允许一条序列 |

押入一张牌 = 它从手牌 / 抽牌堆 / 弃牌堆三处消失，本场战斗不会再抽到。

---

## 7. 编译与减费

### 编译

主动动作：把拼好的序列锁定为可打出的卡，开始每回合减费。

- 必须所有块都已闭合才能编译；
- 栈空不会自动编译，仍可继续押入新的头；
- 编译后内容锁定，不可再押入或弹出。

### 减费

- 编译之后，每回合结束序列费用 −1，下限 0；
- 押入期间不减费；
- 减费只降费用，不降效果。

### 费用牌

费用牌的费用是 −1：

- 单独打出：获得 1 点能量；
- 押入序列：让序列总费用 −1，且不消耗容量。

---

## 8. 回合流程

```
1. 回合开始：恢复能量，抽 5 张
2. 出牌阶段：打出手牌 / 押入合成区 / 闭合 / 弹出（每回合限一次）
3. 按「编译」：把拼好的序列锁定（可选）
4. 打出序列：一次性支付费用，结算效果
5. 回合结束：手牌弃掉；已编译的序列费用 −1
6. 敌人行动
```
