# 由 lzxita 写在前面

**作品名**：中文《静默校园》/ 英文 `Don't Make Noise`
（两者不互译——中文是意象"这里很静"，英文是纪律"你别出声"，对齐《饥荒》的命名法：中文名是状态，英文名 `Don't Starve` 是劝告。）

总结如下：

1. 末日废土风格的**校园求生**游戏，像素风，视角与氛围参考《阿瑞斯病毒》。
2. **弱战斗**：没有丧尸，战斗要素大幅削减，强调**生存压力**而不是对抗。
3. 保留《饥荒》的**三维设计**（体力 / 饱食 / 理智）与**工作台分级**。
4. 材料换成**校园里随处可见的东西**；「树枝」这种校园里真实存在的可以直接保留。
5. 少量**敌对机器人**取代怪物，保留饥荒式的战斗手感（前摇、走位、打带跑）。
6. **校园是静默的，而机器人靠声音找你**——标题即纪律，噪音是本作的核心行为准则。
7. **校门被 AI 锁死**，可以通过击败**西区国家实验室**的大型机器人 boss 取得钥匙，从西区校门逃生。
8. **不限制天数**，boss 结局是一个独立的结局导向，不影响其他内容；多结局可能：**`100` 天后在东区校门得到救援**、**在东区活动中心修好广播站呼叫校外**、**把中区宿舍改成家留下来**。
9. **死亡删档**；床参考《饥荒联机版》原作设计（跳过夜晚、恢复理智），不是手动存档点。
10. **单局 `30~40` 天**（对标《饥荒》打远古织影者的时间跨度），**一日 `8` 分钟，与饥荒同版**。
11. **不强制每晚回家**：光源全部可携带 / 可放置，可以像原版一样在外探索。
12. **有烹饪系统**：类似饥荒的锅，用校园食材组合出有特殊效果的料理。
13. **工作台分层**：前两级可拆解打包、随身携带、随时放下（返还一半材料），高级台参考饥荒**远古塔**不可搬。
14. **校园家具可大量破拆**，作为前期的主要资源来源。
15. **地图是真实的中国科学技术大学本部**：中区（出生）/ 东区 / 西区，通过地下通道与西区天桥相连；最终 boss 在西区国家实验室，广播结局在东区。
16. 这是**电子游戏**，不是桌游。

## 原始数值设定

- 三维上限均为 `100`：体力 / 饱食 / 理智
- 单局 **`30~40` 天 = `4~6` 小时**（对标饥荒打远古织影者；熟练速通 `17` 天）
- **一日 `8` 分钟**（与饥荒同版）：白天 `5` + 黄昏 `1.5` + 夜晚 `1.5`
- 饱食消耗：每分钟 `1.0`（一天 `8` 分钟 ≈ 消耗 `8`）
- 理智：白天缓慢回升，**黄昏 `−1`/分钟（预警）**，**夜晚无光时快速流失**（每分钟 `4`）
- 夜晚无光源时体力流失 **`−18`/分钟**（一夜 `−27`，约三天半口粮）——最经典的饥荒式致死源
- 树枝、草在校园内**保留**，作为采集层材料；**火把**由树枝 + 布条制成
- 夜战物资：火柴 / 蜡烛 / **火把** / 手电筒 / 荧光棒 / **可就地建的营火** / 应急灯
- **睡袋**（一次性，理智 `+10`）可野外过夜；**床**（永久，理智 `+30`）仍是最优解
- 死亡无复活、无回档，**删档重开**（唯一例外：`AED 除颤仪`，全图 `1` 台）
- 机器人**按校区分配**：中区 `2` / 东区 `3` / 西区 `5`，共 `10` 台
- 机器人伤害：普通 **`10`** / 精英 **`20`**，**不下调**
- 烹饪：最多 **`3` 格**食材，`8` 道料理 + 焦炭失败项，配方全部初始可见
- 保鲜设施：食堂冷库（腐坏 ×`0.2`）、宿舍冰箱（腐坏 ×`0.5`）
- **Lv1 宿舍桌面 / Lv2 社团桌可搬**：打包耗 `布条 ×2`、占 `4` 格；拆解返还**一半**材料
- **Lv3 实验室台 / Lv4 电工台固定不可搬**（对标饥荒远古塔）
- **工作台不可建造**，只能搬迁场景原有的——否则会与破拆形成无限刷
- **破拆产出**：课桌 `木板 ×4` / 椅子 `木板 ×1 + 金属板 ×1` / 铁皮柜 `金属板 ×4`；一间教室 ≈ `39` 木板 + `20` 金属板
- **破拆固定台 = 永久失去该等级**（拆实验室台丢液氮罐 → 放弃 boss 路线）
- **地图 = 真实中科大本部**：中区（出生，★☆☆）/ 东区（★★☆）/ 西区（★★★）
- **连接**：中区 ↔ 东区 = **地下通道**（近路，通道内偶有机器人）；中区 ↔ 西区 = **费西路天桥**（需撬铁栅栏 + 清桥上精英）
- **各区特有资源**：中区给食物与基础材料、**东区给精密层**（美工刀 / 胶带 / 电池）、**西区给高级材料**（金属板 / 电机 / 零件）
- **机器人按区分配**：中区 `2` / 东区 `3` / 西区 `5`，共 `10` 台
- **Lv3 实验室台在东区一教、Lv4 电工台在西区配电室**（逼玩家两校区往返）
- **boss** 在西区**国家实验室**的同步辐射装置
- **倒塌建筑**：科技实验楼（西区）、五教（东区樱花大道尽头）、三区各 `1~2` 栋教学楼
- **四个结局**：
  - **逃生** → **西区校门**（校门钥匙 + 门禁卡 + 持续供电）
  - **广播** → **东区活动中心**（广播站钥匙 + 零件 ×`3` + 持续供电，守 `5` 分钟）
  - **救援** → **东区校门**（第 `100` 天走到即可，无需道具）
  - **留下** → **中区 1 号宿舍楼**（把宿舍改造成家，主动不离开）
- **广播结局与救援结局互斥**（修好广播站 = 主动求救）；逃生 / 广播 / 留下三个主动动作之间也互斥

## 历次平衡决策

| 项目 | 结论 |
|---|---|
| 「夜间巡逻」设定 | **删除**。改为**少量敌对机器人**替代，保留饥荒式战斗 |
| 战斗定位 | **允许战斗，但打了亏体力**（用体力换材料，不是用材料换体力） |
| 空手伤害 | **给 `3` 点**，防止玩家被机器人堵住时彻底死局 |
| 通关条件 | **钥匙 + 门禁卡 + 持续供电**三层门槛（不是拿到钥匙就结束） |
| 天数上限 | **不设上限**。多结局导向：逃生结局 / 救援结局（`100` 天）/ **广播结局** / 滞留结局（死亡） |
| **单局时长** | **`30~40` 天 = `4~6` 小时**（`v1.3`）。原 `7~10` 天作废——太短会让清剿周期（`7` 天）与天气轮转（`21` 天）在一局里都跑不完 |
| **一日长度** | **`8` 分钟，与饥荒同版**（`v1.3`：白天 `5` + 黄昏 `1.5` + 夜晚 `1.5`）。`18` 分钟与 `12` 分钟均作废——`12` 分钟会让玩家一天跑完两栋楼，时间压力消失 |
| **是否强制每晚回家** | **不强制**（`v1.3`）。光源全部可携带 / 可放置，新增**火把**与可就地建的**营火**，另有一次性**睡袋**可野外过夜 |
| **夜晚无光惩罚** | **`−18` 体力/分钟**（`v1.3`，一夜 `−27`）。夜晚压到 `1.5` 分钟后，原 `−6` 只能造成 `−9`，忘带灯的代价轻到可忽略 |
| **烹饪系统** | **新增**（`v1.3`）。电饭锅 / 电磁炉，最多 `3` 格食材，`8` 道料理 + 焦炭失败项，配方**初始全部可见** |
| **烹饪收益方向** | **不提升饱食效率**（`v1.3`）。饱食靠生吃打底，**理智与体力靠烹饪**——否则烹饪只是效率工具，玩家没有取舍 |
| **工作台可否搬迁** | **分层**（`v1.4`）：**Lv1 / Lv2 可拆解打包随身带**，**Lv3 / Lv4 固定不可搬**（对标饥荒远古塔）。既有建家自由度，又保住"地图即进度条" |
| **工作台可否建造** | **不可建造**（`v1.4`）。只能搬迁场景原有的台子。若允许建造，会出现"拆椅子 → 造台 → 拆台 → 回收一半"的**无限刷** |
| **破拆机制** | **新增**（`v1.4`）。校园家具全部可拆，一间教室 ≈ `39` 木板 + `20` 金属板，是前期资源爆发口；家具**不可再生** |
| **破拆固定台** | **永久失去该等级**（`v1.4`）。拆实验室台 = 放弃 boss 路线（液氮罐没了）；拆电工台 = 放弃逃生结局（供电台没了）。刻意的不可逆抉择 |
| **地图取景** | **真实的中科大本部**（`v1.5`）：中区出生 / 东区广播站 / **西区国家实验室 boss**。不另设虚构场景 |
| **三区连接** | **中区 ↔ 东区 = 地下通道**（真实存在）；**中区 ↔ 西区 = 费西路天桥**（真实校区被肥西路隔开，需撬铁栅栏 + 清桥上精英） |
| **三区难度分层** | **中区 ★☆☆ / 东区 ★★☆ / 西区 ★★★**。资源按区特化：中区食物基础、**东区精密层**、**西区高级材料**。用资源分布而不是规则来驱动推进 |
| **倒塌建筑** | 科技实验楼（西区）、五教（东区樱花大道）、三区各 `1~2` 栋。既省美术工作量，也给地图划出天然边界、降低认知负担 |
| **饱食消耗** | **`1.0/分钟`**（每日 `8`）。原 `1.5` 在长周期下需要 `80` 份食物，校园装不下 |
| **保鲜设施** | **新增**（`v1.2`）：冷库 ×`0.2` / 冰箱 ×`0.5`。没有它，`30~40` 天会退化成重复觅食 |
| 食物 | **必须可再生**（否则 `100` 天结局无法达成）；绿化带每日刷新，售货机每 `2` 日补 `1~2` 份 |
| 饥饿归零 | **持续掉体力直到死亡**，不能只是掉理智（否则无限生存会退化成挂机） |
| 防躺平机制 | **A + B 组合**：AI 定期清剿（`7` 天一波，第 `35` 天起**封顶循环**）+ 天气慢周期（`21` 天一轮） |
| 清剿封顶 | **必须封顶**（`v1.2`）。无限递增会让 `100` 天救援结局在数学上不可达 |
| Boss 战形式 | **C + D 组合**：进门前置条件 + 三阶段战斗（护盾期 / 战斗期 / 暴走变暗） |
| Boss 数值 | 体力 **`900`**（消防斧 `45` 下；一把斧头留 `15` 下耐久应付暴走期精英）；暴走期召唤**精英机器人 ×`2`** |
| Boss 容错 | **允许随时撤退**，血量不重置（多次尝试，而非一次删档） |
| 存档 | **自动存档，玩家无感**；死亡真删档 |
| 床 | 参考《饥荒联机版》：**跳过夜晚 + 恢复理智 `+30` + 消耗饱食 `−30`**，需工作台 Lv2 制作 |
| 睡袋 | **一次性**（理智 `+10`，饱食 `−10`），供野外过夜，工作台 Lv2 制作 |
| 复活道具 | **保留 `1` 个一次性道具**（`AED 除颤仪`）：位于医务室，占 `2` 格背包，复活回 `30` 体力 |
| 第三个结局 | **做**。**广播结局**：修好广播站并供电，守住广播站 `5` 分钟呼叫校外 |
| **逃生结局地点** | **西区校门**（`v1.6`）。终局动作集中在西区，但门禁卡在东区行政楼——**保证玩家三个校区都必然经历过** |
| **救援结局地点** | **东区校门**（`v1.6`），第 `100` 天触发。不给地点会让长线经营缺一个收尾动作 |
| **广播 ↔ 救援** | **互斥**（`v1.6`）。修好广播站 = 主动求救，`100` 天救援线路终止 |
| **第四个结局** | **新增「留下结局」**（`v1.6`）：把中区 1 号宿舍楼改造成家，主动选择不离开。让"最弱的校区"拥有一条完整路线 |
| 机器人伤害 | **不下调**（普通 `10` / 精英 `20`）。**玩家需要一点恶意**——前摇 `1.2` 秒是机会，不是保证 |
| **作品名 / 目录名** | **《静默校园》/ `Don't Make Noise`**（`v1.7`），目录 `Noise/`。中英文**不互译**：中文是意象，英文是纪律。原《下课铃》`Bell/` 作废 |
| **静默准则** | **升格为规则**（`v1.7`，新增 3.4）：破拆 / 打包 / 战斗三条噪音规则统一到"静默"概念下，给出**噪音半径分级表**（中 / 大 / 极大）；图书馆等空旷软质地面**噪音半径减半** |
| **三维上限** | **`150 / 150 / 150`**（`v1.8`，原 `100`）。**宪法级改动**：只有三维同步缩放，"一顿饭回 `30` 饱食"与"一次交战掉 `30` 体力"的比例才不会乱。配套：饱食消耗 `1.0`→`1.5`/分钟、饱食归零惩罚 `−20`→`−30` |
| **夜晚无光惩罚** | **`−33.3`/分钟（一夜 `−50`）**（`v1.8`，原 `−18`/一夜 `−27`）。三维提到 `150` 后原值只占上限 `18%`，提到 `−50` 才恢复到**上限的 `33%`**（"一夜 = 三天半口粮"的分量） |
| **护甲机制** | **百分比吸收**（`v1.8`）：吸收率决定减伤比例，**耐久扣"吸收掉的那部分伤害"**。铁皮护甲 `85%` / `900` 耐久，**对标饥荒联机版木甲（`80%` / `450`）**。旧方案（吸收固定点数）对 boss 完全无效，已废 |
| **装备槽** | **`3` 槽：头 / 手 / 身体**（`v1.8`）。手部只装武器（**手持光源也占手**）；**护甲 / 背包 / 衣物抢身体槽**，但**护甲可放背包里、临战 `2` 秒换上**——护甲因此是"随身携带"而非"日常穿着" |
| **体温系统** | **新增**（`v1.8`）：双向（过冷 `<20` / 过热 `>80`），`0~100` 刻度（沿用三维单位，不引入摄氏度）；新增 **`酷暑`** 天气，`21` 天轮转改为晴 `5`/雨 `4`/沙尘 `4`/寒潮 `4`/酷暑 `4`（**保住 `21` 是 `7` 的整数倍**） |
| **判定基建** | **`14` → `16` 个词**（`v1.8`）：新增 **`流血`**（每秒 `−1` 体力，可叠 `3` 层）与 **`中毒`**（**持续 `−2` 体力/秒 `60` 秒**）。中毒**不是**"加速饥饿"——那会让饱食净减 `90`，把玩家推进"饱食归零→掉体力上限→必死螺旋" |
| **材料堆叠** | **参考饥荒**（`v1.8`）：散料 `20`/格、板材与布类 `10`/格、食物 `5`/格、零件 `10`、电池 `5`；**全部"物品"不可堆叠**。背包压力从"要不要捡"转为"**带哪几件**" |
| **打包建筑** | **不占背包格**（`v1.8`，对齐饥荒）：走独立的"建筑"栏，搬家成本只剩 `布条 ×2`。原"占 `4` 格"会让"允许搬台子"这条设计在实测中不可用 |
| **拆解返还** | **`50%` 向上取整**（`v1.8`，对齐饥荒）：**成本为 `1` 的稀有材料原样返还**（如发电机返还 `电机 ×1`）。让"稀有材料可迁移、批量材料留在原地" |
| **合成配方书** | **只放"能造的"**（`v1.8`）：无配方的材料与不可制作物品全部归入独立的"掉落"栏。配方书从 `90+` 条压到 `46` 条 |
| **烹饪判定** | **饥荒式「标签 + 优先级」**（`v1.8`，推翻了 `v1.3` 的精确配方）：`3` 格锅、最少 `2` 份食材；把食材标签相加后从高优先级往下试，第一条满足的就是结果；全不满足 → 焦炭。`5` 个区分标签（`鲜` / `蛋` / `豆` / `辣` / `补`）让 `23` 条配方里仅 `1` 处需要优先级兜底 |
