# 由 lzxita 写在前面

总结如下：

1. 基础牌只有「苹果」，一张苹果可以发挥「杀」或「桃」的作用——同一张牌、同一次额度，攻与守互相挤占。
2. 特色在合成：用「虫子」「毒药」等材料把苹果腌成「烂苹果」「毒苹果」等更强的牌。
3. 装备卡与稀有卡做联动的梗，例如「苹果迫击炮」（植物大战僵尸2）、「附魔金苹果」（Minecraft）。
4. 每回合只准使用有限张牌，所以也允许将多个「苹果」进行合成为一张。
5. 各个玩家身份平等。
6. 这是**电子游戏**，不是实体卡牌。

## 原始数值设定

- 苹果 +1 / −1
- 虫子：**只有回血，+0.5**，不会产生伤害
- 烂苹果 −3
- 毒苹果：原为 −5，后改为 **−3 + 两回合毒伤，且禁止回血**
- 金苹果 +5
- 附魔金苹果 +10（**全游戏只有一张**）
- 初始血量 10，初始手牌 5，每回合摸 2 张
- **0.5 血按存活计算**（血量是小数，0 < 血 ≤ 上限即存活）
- **毒药数量远少于虫子**（约 1 : 3）
- **攻击距离为 1**（只能打左右邻座），由独有的「苹果迫击炮」增加

## 果渣（死亡状态）的平衡约束

初版设定是：咬一口 = 抽 2 张牌 + 回 1 点血，无限次；可无限次复活。实测推演后判定**超模**，改为四条约束：

1. **咬只回 1 点血，不再给牌**（与"吃一张苹果"收益持平）
2. **每颗果渣终生只能被咬 3 次**（资源有限、会枯竭）
3. **只能变一次果渣**，第二次死亡即永久出局（死亡有终局性）
4. **发酵层数上限 3 层 = 复活门槛**，所以"报复"和"复活"二选一；原 3 层的「同归」（互换体力、直接送走满血玩家）太强，改为「腐化」（体力上限永久 −2）

## 座位环

- 攻击距离为 1（只打左右邻座）
- **果渣占座**（它随时会复活，且是活人之间的缓冲）
- **永久出局者不占座，座位环收缩**：每永久出局一人，环小一格，所有人更近——这是天然的对局收束机制

## 其余已定项

| 项目 | 结论 |
|---|---|
| 中毒叠加 | **只叠时长，不叠伤害** |
| 巨型烂苹果（3 苹果 + 虫子 → 4 点） | **删除**，不设上限输出 |
| 毒抗血清 | 数量 = **毒药的一半**（毒药张数 = 人数） |
| 装备牌 | **人数 × 1.2**，可以丢弃，丢 1 张换抽 1 张 |
| 手牌上限 | **= 当前体力**；溢出不弃牌、仍可使用，但不能再抽 |
| 6 人局血量 | **降回 10**（与 4/5 人一致） |
| 座位环收缩 | **不延迟**，出局立即收缩 |
